# TaskFlow AI — ระบบจัดตารางเรียนและลดสภาวะหมดไฟ สาขาวิศวกรรมคอมพิวเตอร์

> **โครงงาน การจัดตารางเรียนสาขาวิศวะคอม**  
> *"TaskFlow AI" แอปพลิเคชันผู้ช่วยอัจฉริยะเพื่อการจัดการเวลาและลดสภาวะหมดไฟ ขับเคลื่อนด้วยเทคโนโลยี Generative AI และ Constraint Satisfaction Problem (CSP)*

---

## 🌟 ฟีเจอร์หลักในระบบ (Core Features)

1. **ระบบสมาชิกและเข้าสู่ระบบ (User Authentication)**:
   - สมัครสมาชิกใหม่ (Register) ด้วยรหัสนักศึกษา, ชื่อ-นามสกุล, อีเมล และรหัสผ่าน
   - เข้าสู่ระบบ (Sign In) ด้วยรหัสนักศึกษา หรือ อีเมล
   - ปุ่มเข้าสู่ระบบด่วนด้วยบัญชีตัวอย่าง (1-Click Demo Account: กิตติพงษ์ วิศวะคอม `65010999`)
   - แยกข้อมูลตารางเรียน งานที่มอบหมาย และประวัติการเช็กอินของแต่ละผู้ใช้อย่างปลอดภัย
2. **ระบบเพิ่มและจัดการตารางเรียนของตนเอง (Custom Class Schedule Management)**:
   - ผู้ใช้สามารถเพิ่มรายวิชาเรียนของตนเองได้ (`+ เพิ่มวิชาเรียน`):
     * รหัสวิชา, ชื่อวิชา, วันที่เรียน (จันทร์-อาทิตย์), เวลาเริ่มต้น-สิ้นสุด, ห้องเรียน/ลิงก์, ผู้สอน, และสีประจำวิชา
   - ระบบ **Constraint Satisfaction Problem (CSP)** จะคำนวณใหม่ทันทีเพื่อกันช่วงเวลาเรียน และไม่จัดงานย่อยมาซ้อนทับ
   - เมนู **"จัดการตาราง"**: ดูวิชาทั้งหมด ลบวิชาที่ไม่ต้องการ หรือรีเซ็ตกลับเป็นตารางวิศวะคอมเริ่มต้น
3. **Daily Check-in & Dynamic Variable (ประเมินอารมณ์และระดับพลังงาน)**:
   - บันทึกสภาพอารมณ์ ระดับพลังงานในแต่ละวัน (ต่ำ, ปานกลาง, สูง) และชั่วโมงการนอนหลับ
   - คำนวณดัชนีความเสี่ยงต่อสภาวะหมดไฟ (Burnout Risk Index) พร้อมคำแนะนำทางจิตวิทยาเชิงบวก
4. **AI Task Deconstruction (ย่อยเอกสารคำสั่งงานด้วย Generative AI)**:
   - รองรับการอัปโหลดไฟล์คำสั่งงานแบบ PDF (สกัดข้อความด้วย `pypdf`) หรือรูปภาพ/ข้อความ
   - เชื่อมต่อโมเดลภาษาขนาดใหญ่ (LLMs เช่น Google Gemini 1.5) เพื่อย่อยงานชิ้นใหญ่ให้เป็นขั้นตอนย่อย (Subtasks) ที่ทำเสร็จได้จริงใน 30 - 45 นาที
   - จำแนกระดับภาระการคิด (Cognitive Load: High, Medium, Low)
5. **Dynamic Workload Adjustment (ปรับภาระงานแบบยืดหยุ่น)**:
   - เมื่อระดับพลังงานต่ำ (Low Energy) ระบบจะปรับสลับงานยาก (High-Cognitive) ออกไปวันหยุด และแนะนำเฉพาะงานง่าย (Low-Cognitive) เพื่อป้องกันความเครียดสะสม
6. **Focus Mode (Pomodoro Timer 30-45 นาที)**:
   - นาฬิกาจับเวลาเพื่อการโฟกัสทีละขั้นตอนย่อย พร้อมระบบเช็กลิสต์และ Positive Reinforcement
7. **Google Calendar Sync (.ics Export)**:
   - ส่งออกตารางเรียนและกำหนดงานย่อยเป็นไฟล์ `.ics` นำไปซิงค์กับ Google Calendar หรือ Calendar บนสมาร์ตโฟนได้ทันที
8. **AI Timetable Scanner & Auto-Replacement (ดึงข้อมูลตารางเรียนจากภาพ/ไฟล์มาแทนของเดิม)**:
   - สแกนรูปภาพตารางเรียน (PNG/JPG/WEBP) ด้วยโมเดล AI OCR บนเครื่อง (`rapidocr-onnxruntime`) และรองรับ Gemini Vision
   - ดึงข้อมูลจากไฟล์ PDF สำนักทะเบียนหรือใบลงทะเบียนเรียน
   - แท็บคัดลอกและวางข้อความตารางเรียนจากเว็บลงทะเบียนของมหาวิทยาลัย (SIS Text Paste)
   - หน้าต่างตรวจสอบรายวิชา (Review Modal) พร้อมตัวเลือกแทนที่ตารางเรียนเดิมทั้งหมด (Auto-Replace) และคำนวณ CSP จัดตารางทำงานให้อัตโนมัติทันที

## 🚀 วิธีการเปิดใช้งานระบบ (How to Run)

1. ดับเบิลคลิกไฟล์ `run_server.bat` หรือเปิด Terminal แล้วรันคำสั่ง:
   ```bash
   python app.py
   ```
2. เปิดเบราว์เซอร์ไปที่:
   ```
   http://127.0.0.1:5000
   ```
